# Simple Python Interpreter

## About
A simple Pascal-style interpreter implemented in Python.

## Features
- Lexical analysis using a Lexer
- Parsing expressions and statements
- Abstract Syntax Tree (AST) construction
- Arithmetic operations and variable assignments
- Interpreter execution using a symbol table

## Technologies
- Python
- Object-Oriented Programming

## Example
```pascal
BEGIN
    a := 10;
    b := 20;
    c := a + b * 2;
END.
```

Expected output:
```python
{'a': 10, 'b': 20, 'c': 50}
```

## How to Run
Run the Python file using:

```bash
python interpreter.py
```
